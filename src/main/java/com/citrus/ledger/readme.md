# Ledger Module

這是貸款系統的**會計模組**，負責複式簿記。

---

# 1. 模組定義

| 項目 | 說明 |
|------|------|
| 角色 | 會計部門 |
| 對外 API | ❌ 僅供內部調用 |
| 核心職責 | 複式簿記、計息、餘額管理 |

---

# 2. 核心概念

### 複式簿記
```
放款 ₹50,000：
    借 (Debit)：應收帳款 +₹50,000
    貸 (Credit)：銀行存款 -₹50,000
    → 借貸必平衡
```

### 不可變性
- 禁止 UPDATE
- 錯誤修正用「紅沖藍補」

---

# 3. 主要功能

| # | 功能 | 說明 | 優先級 |
|---|------|------|-------|
| 1 | **記帳** | 寫入會計分錄 | P0 |
| 2 | **餘額查詢** | 查訂單應收餘額 | P0 |
| 3 | **計息** | 每日計算利息 | P0 |
| 4 | **日結快照** | 每日餘額快照 | P1 |
| 5 | **紅沖藍補** | 錯誤修正 | P1 |

---

# 4. API 清單

### Phase 1

| API | 用途 | 呼叫者 |
|-----|------|-------|
| `POST /ledger/entry` | 寫入分錄 | knockoff |
| `POST /ledger/balance/{orderId}` | 查詢餘額 | 各模組 |

### Phase 2

| API | 用途 | 呼叫者 |
|-----|------|-------|
| `POST /ledger/journal/{orderId}` | 查詢分錄明細 | 後台 |
| `POST /ledger/accrual/run` | 執行計息 | loancron (MQ) |
| `POST /ledger/reversal` | 紅沖藍補 | 後台 |

---

# 5. MQ 消費

| 事件 | 來源 | 說明 |
|-----|------|------|
| DISBURSEMENT_COMPLETED | pay | 放款完成 |
| PAYMENT_RECEIVED | pay | 收到還款 |
| ACCRUAL_RUN | loancron | 計息觸發 |

---

# 6. 設計考量

| 項目 | 建議 |
|-----|------|
| **不可變** | 只能 INSERT |
| **借貸平衡** | 每次驗證 |
| **精度** | 用 BigDecimal |
| **冪等** | 用事件 ID 去重 |
