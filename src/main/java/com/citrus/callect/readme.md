# Callect Module

這是貸款系統的**催收模組**，負責逾期追討。

---

# 1. 模組定義

| 項目 | 說明 |
|------|------|
| 角色 | 催債部門 |
| 對外 API | ❌ 僅供 loancron 觸發 |
| 核心職責 | 分桶催收、自動發送、PTP 追蹤 |

---

# 2. 分桶策略

| Bucket | DPD | 處理方式 |
|--------|-----|---------|
| B0 | 1-30 | 自動 SMS |
| B1 | 31-60 | 電話催收 |
| B2 | 61-90 | 外包催收 |
| NPA | 90+ | 法律行動 |

---

# 3. 主要功能

| # | 功能 | 說明 | 優先級 |
|---|------|------|-------|
| 1 | **分桶** | 依 DPD 分類 | P0 |
| 2 | **自動催收** | B0 發 SMS | P0 |
| 3 | **案件指派** | 嚴重的給人工 | P1 |
| 4 | **PTP 追蹤** | 還款承諾追蹤 | P1 |

---

# 4. API 清單

### Phase 1

| API | 用途 | 呼叫者 |
|-----|------|-------|
| `POST /callect/case/create` | 建立催收案件 | loancron (MQ) |

### Phase 2

| API | 用途 | 呼叫者 |
|-----|------|-------|
| `POST /callect/case/{orderId}` | 查詢案件 | 後台 |
| `POST /callect/case/{caseId}/note` | 新增催記 | 催收員 |
| `POST /callect/case/{caseId}/ptp` | 記錄 PTP | 催收員 |
| `POST /callect/sms/send` | 發送 SMS | 系統 |

---

# 5. 和其他模組的關係

```
loancron (逾期檢測)
    │ MQ
    ▼
callect (催收)
    │ 催回成功
    ▼ MQ
loancore (更新狀態)
```
