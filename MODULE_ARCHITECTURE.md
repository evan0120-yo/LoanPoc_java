# 貸款系統模組架構分析

| 模組 | 角色定位 | 對外 API？ | 核心職責 |
|------|---------|-----------|---------|
| **origin** | 審核官 + 定價師 | ❌ 內部 | 決策引擎、額度計算、利率定價 |

## 2. 關鍵問題：誰是對外 API 入口？

根據 readme 分析，**目前沒有明確的對外入口模組**。

### 現有 readme 的設計
```
loancore.readme 說：
    「loancore → 各模組：同步呼叫或 Command MQ」
    「各模組 → loancore：MQ 事件通知」

origin.readme 說：
    「loancore → origin：同步呼叫（審核是關鍵路徑）」
```

這暗示 **loancore 是協調者**，但沒說清楚**誰接收前端請求**。

## 3. 建議架構：origin 作為前端入口

### 為什麼選 origin？

| 考量 | 說明 |
|------|------|
| **語意正確** | origin = 起源/發起，適合作為貸款申請的起點 |
| **職責清晰** | origin 負責「接收申請 + 決策」，不涉及後續放款還款 |
| **loancore 隱身** | loancore 專注於協調，不直接面對前端 |

## 5. 各模組通訊方式

| 來源 | 目標 | 方式 | 原因 |
|------|------|------|------|
| 前端 → origin | origin | **同步 HTTP** | 需要立即回應 |
| loancron → bureau/origin | bureau/origin | **MQ 或同步** | 批次處理 |
| origin → loancore | loancore | **同步 HTTP** | 建單需要 ID |
| origin → lsp | lsp | **MQ** | 非同步導流 |
| loancore → sign | sign | **同步 HTTP** | 關鍵路徑 |
| sign → loancore | loancore | **MQ** | 狀態更新 |
| loancore → pay | pay | **同步 HTTP** | 放款需即時 |
| pay → ledger | ledger | **MQ** | 記帳非同步 |
| pay → knockoff | knockoff | **MQ** | 還款沖銷 |
| knockoff → ledger | ledger | **同步** | 需原子性 |
| loancron → callect | callect | **MQ** | 逾期通知 |
| loancron → ledger | ledger | **MQ** | 計息觸發 |

## 6. 建議的 loancron 角色

**loancron 只做觸發，不存業務資料**

| ✅ 正確職責 | ❌ 錯誤職責 |
|------------|------------|
| 定時觸發審批流程 | 存儲用戶申請資料 |
| 日切計息 / 逾期檢測 | 直接處理業務邏輯 |
| 發 MQ 給其他模組 | 直接調用 DB |

### loancron 的排程任務

| 任務 | 觸發時間 | 調用模組 |
|------|---------|---------|
| 處理待審批申請 | 每 5 分鐘 | origin (via MQ) |
| 日切計息 | 每日 00:00 | ledger (via MQ) |
| 逾期檢測 | 每日 00:30 | loancore (via MQ) → callect |
| 自動扣款 | 每日 09:00 | pay (via HTTP) |
| 簽約超時檢測 | 每日 02:00 | loancore (via MQ) |

## 7. 結論與建議

### Phase 1 開發順序

1. **origin** - 對外入口 + 申請記錄
2. **loancore** - 訂單建立 + 狀態機 (已部分完成)
3. **loancron** - 排程觸發
4. **bureau** - 徵信 (可 Mock)
5. **sign** - 簽約 (可 Mock)
6. **pay** - 放款 (可 Mock)

### 架構決策

| 決策 | 建議 |
|------|------|
| 前端入口 | **origin** |
| 狀態機 | **loancore** |
| 排程 | **loancron** (只觸發，不存業務資料) |
| 資料存儲 | 申請在 origin，訂單在 loancore |
